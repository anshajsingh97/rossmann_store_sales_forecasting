# Rossmann Store Sales Forecasting

**Author:** Anshaj Singh  

## Project Summary
This repository contains a time series forecasting project focused on predicting daily sales for selected Rossmann drug stores. The objective is to improve forecast accuracy by leveraging historical sales data along with store-level and calendar-based features, thereby supporting better operational and inventory planning.

## Problem Statement
Rossmann operates thousands of drug stores across Europe, where store managers are responsible for forecasting daily sales. Sales are influenced by multiple factors such as promotions, holidays, seasonality, competition, and locality. Manual forecasting leads to inconsistent accuracy and suboptimal decision-making.

This project aims to build a data-driven forecasting solution to predict store-level sales for the next six weeks.

## Business Objective
- Forecast daily sales accurately for selected Rossmann stores
- Reduce variability and subjectivity in manual forecasts
- Capture the impact of promotions, holidays, and seasonality
- Provide reliable short-term sales forecasts for business planning
